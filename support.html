FAQ

Frequently asked

Is Vortex really free?
Yes. The client, all 65+ mods, and core cosmetics are completely free. Optional Credits (CR) only unlock cosmetic items — never gameplay advantages.
Which Minecraft versions are supported?
Vortex supports 1.8 through 1.21, including OptiFine bundles and performance profiles for every version.
Will I get banned from Hypixel or other servers?
Vortex is fully server-friendly and built anti-ban aware. All mods comply with the most popular server rules — mods like toggle sneak are server-configurable.
Can I run Vortex on a low-end PC?
Yes. The performance pipeline is tuned to run on 4GB RAM and integrated GPUs, while the benchmark section shows how much headroom you can gain.
