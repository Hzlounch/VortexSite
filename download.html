VortexLauncher is the official Windows client for Vortex. It installs in a few steps, signs in with your Microsoft Minecraft account, and keeps versions, profiles, and mods in one place. Support lives on Discord and this website if anything gets stuck.

Setup

Four steps from download to play.

This is the establishment flow. Finish it once, then VortexLauncher remembers your account and profiles.

1

Download the launcher

Get VortexLauncher for Windows from the button at the bottom of this page. That file is the installer we ship from the dist build.

2

Install and open it

Run the installer, then open VortexLauncher. You should see the Vortex logo in the top-left Client menu.

3

Sign in with Microsoft

Use a Microsoft account that owns Minecraft. Playing without that account is not supported.

4

Press Play

Pick a profile, wait for the first prepare pass, then launch. If you need help, open Support in the launcher — it goes to Discord or this site.
