System Requirements

Vortex is highly optimized to run on both potato PCs and high-end rigs. Here is what we recommend for the best experience.

  • OS: Windows 10/11, macOS 10.14+, Ubuntu 20.04+
  • CPU: Intel Core i3 or AMD equivalent
  • RAM: Minimum 4GB (8GB recommended)
  • GPU: OpenGL 4.5 compatible graphics
  • Storage: 2GB available space
  • Java: Built-in (No manual Java install required)
